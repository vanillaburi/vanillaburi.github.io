ทุกครั้งที่ เพิ่มบทความใหม่ ต้องมาทำ 4 ขั้นตอนนี้ด้วย ไม่งั้น Google จะไม่รู้ว่ามีบทความนี้อยู่ (บทความเก่าที่มีอยู่แล้วไม่ต้องทำซ้ำ)

ขั้นตอน

  1. เพิ่ม/แก้บทความในแท็บ "จัดการบทความ" ให้เรียบร้อยก่อน (ต้องมี Slug ทุกบทความ)
  2. กดปุ่ม "สร้างโค้ด Sitemap" ด้านล่างนี้ — ระบบจะสร้างโค้ดให้ครบทุกบทความอัตโนมัติ
  3. คัดลอกโค้ดที่ได้ → ไปที่ไฟล์ sitemap.xml บน GitHub → กดไอคอนดินสอ
  4. ลบเฉพาะส่วน <url>...</url> ที่เป็นของบทความทั้งหมด (เก็บ 2 อันแรกที่เป็นหน้าแรกกับหน้า blog.html ไว้เหมือนเดิม อย่าลบ) แล้ววางโค้ดใหม่แทนที่ตรงนั้น ก่อนบรรทัด </urlset> → Commit changes
